# Python DA Assignment 2 – Data Visualization

## Project Overview
This project focuses on data visualization using Python. The Seaborn Taxis dataset is used to explore trip details and understand patterns through different charts and graphs.

## Dataset
- **Dataset:** Taxis
- **Source:** Seaborn built-in dataset

## Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Tasks Performed

### 1. Data Loading and Cleaning
- Loaded the Taxis dataset.
- Checked for missing values.
- Handled missing values using appropriate methods.

### 2. Visualizations using Matplotlib and Pandas
- Line Chart – Fare Over Time
- Bar Chart – Total Fare by Pickup Borough
- Pie Chart – Trips by Payment Method
- Histogram – Distribution of Distance
- Box Plot – Tip Amount by Pickup Borough

### 3. Visualizations using Seaborn
- Count Plot – Trips by Pickup Borough
- Scatter Plot – Distance vs Fare
- Heatmap – Correlation Between Numerical Variables
- Pair Plot – Pairwise Relationships
- Violin Plot – Fare Distribution by Payment Method

## Key Learning Outcomes
- Learned to handle missing values using Pandas.
- Practiced creating different visualizations using Matplotlib and Seaborn.
- Explored relationships between numerical variables.
- Improved understanding of data distribution and patterns.

## Conclusion
This assignment helped me gain practical experience in Python data visualization and understand how different charts can be used to explore and present data effectively.
